PACOTE ENXUTO · SOMENTE AS DUAS POSES

Seu Pokémon de frente.
E de costas.

Uma imagem para cada posição. Baixe os PNGs separados ou um ator .sprite3 que já contém as duas fantasias, chamadas frente e costas.

Baixar imagens (.zip) ↓Ver como programar os movimentos →
OPÇÃO 1 · PNG

Envie a frente como ator. Depois, em Fantasias → Enviar Fantasia, envie a imagem de costas para o mesmo ator.

OPÇÃO 2 · .SPRITE3

Use Enviar Ator para importar o arquivo. As duas fantasias já estarão organizadas juntas.

DEPOIS · PROGRAMAR

Use Movimento para andar e pular. Use mude para a fantasia para escolher frente ou costas.

Os PNGs têm fundo transparente. Se a imagem abrir no navegador, use o botão direito → Salvar imagem como. Extraia os pacotes ZIP antes de enviar os arquivos ao Scratch.
